Flash a board from the browser

Plug a Bonsai board (Seeed XIAO ESP32-S3 Sense) into a USB port, pick a firmware release and write it. Nothing is uploaded anywhere: the release is downloaded from GitHub and pushed over the serial port by your own browser.

devices

The board shows up as a serial port. If nothing appears in the browser prompt, hold BOOT, tap RESET, release BOOT, then try again.
